# 🚀 ZapFilter CRM - Filtros Rápidos & Quadro Kanban no WhatsApp Web

Extensão completa para Google Chrome e Microsoft Edge (Manifest V3) que transforma o seu **WhatsApp Web** em uma central de atendimento e **CRM com Quadro Kanban**.

---

## 🌟 Principais Recursos

### 1. 📊 Quadro Kanban / Funil de Atendimento (CRM)
- **Botão no Header**: Acesse o quadro Kanban diretamente pelo botão **"Quadro Kanban"** no topo da lista.
- **Colunas Padrão**:
  - 📥 **Novos Leads**
  - 💬 **Em Atendimento**
  - 📄 **Proposta Enviada**
  - ⏳ **Aguardando Pagamento**
  - ✅ **Fechado / Ganho**
  - ❌ **Perdido**
- **Arraste e Solte (Drag & Drop)**: Mova os contatos entre as etapas com animação fluida.
- **📥 Capturar Chats do WhatsApp**: Botão de 1 clique para importar os contatos da sua lista de conversas para o Kanban.
- **➕ Adicionar Leads**: Cadastre contatos com telefone, valor da negociação e anotações.
- **💬 Abrir Chat**: Botão direto no card para abrir a conversa no WhatsApp Web.
- **Persistência Local**: Tudo é salvo automaticamente no seu navegador.

### 2. ⚡ Barra de Filtros Rápidos
- 🌟 **Todas**: Visualização padrão.
- 📩 **Não Lidas**: Apenas conversas com mensagens pendentes + contador.
- 👥 **Grupos**: Exclusivamente grupos e comunidades.
- 👤 **Contatos**: Apenas conversas 1 a 1.
- ⏳ **Aguardando**: Conversas onde a última mensagem foi do cliente e aguarda resposta.

---

## 🛠️ Como Instalar e Atualizar

1. Acesse `chrome://extensions/` no Chrome ou `edge://extensions/` no Edge.
2. Ative o **Modo de Desenvolvedor**.
3. Se já instalou, clique no botão **Recarregar (🔄)** no card do ZapFilter.
4. Caso seja a primeira vez, clique em **Carregar sem compactação** e selecione a pasta:
   ```
   d:\Empresa\extensao_whatsapp
   ```
5. Abra ou dê **F5** na página do [WhatsApp Web](https://web.whatsapp.com).
